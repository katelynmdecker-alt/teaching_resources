Lesson 2: Solving by Factoring

Finding ground-intercepts using the Zero Product Property.

The goal is to find two numbers that fit both parts of the X, allowing us to rewrite ax² + bx + c = 0 as (x + m₁)(x + m₂) = 0.

Zero Product Property

If two things multiply to zero, one of them must be zero. This is how we find the specific values for 'x'.

(x - 3)(x + 5) = 0
➔ x = 3, x = -5

Step-by-Step Factoring Scaffolding

  1. Standard Check: Ensure the equation is in standard form: \( ax^2 + bx + c = 0 \).
  2. Identify Target: Identify your \(a, b,\) and \(c\). Note that you need two numbers that multiply to \( a \cdot c \) and add to \( b \).
  3. Fill the Organizer: Place these targets into the X-Organizer above to find your factors \( m_1 \) and \( m_2 \).
  4. Binomial Write-up: If \( a = 1 \), the factors are simply \( (x + m_1)(x + m_2) \).
  5. The ZPP: Set each factor equal to zero and solve for the roots.
